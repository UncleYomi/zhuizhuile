# 贪吃蛇小游戏项目计划

最后更新：2026-10-05

这份文件用于保存已经确认的项目方向、阶段安排和完成情况。后续继续开发时，应先阅读本文件和项目根目录的 `README.md`。

## 项目目标

和小学一年级的小朋友一起完成一个简单、有个人特色的贪吃蛇网页游戏。游戏最终可以通过一个公开链接分享，玩家无需安装软件，在手机、平板或电脑上即可体验。

第一版坚持以下原则：

- 规则一眼就能看懂，一局时间控制在几分钟内。
- 先完成核心玩法，再添加美术、声音和扩展功能。
- 不要求玩家注册或登录，也不收集任何个人信息。
- 项目由成年人管理，小朋友主要参与主题、角色、食物、颜色、声音和试玩。
- 使用零依赖的 HTML、CSS 和 JavaScript，降低运行、维护和发布难度。

## 已确定的技术方案

- 使用 Canvas 绘制游戏地图、蛇和食物。
- 使用 JavaScript 处理移动、转向、成长、计分和碰撞。
- 第一阶段支持电脑键盘方向键和 WASD。
- 第三阶段增加适合手机和平板的大号方向按钮。
- 暂不使用服务器、数据库、用户系统或在线排行榜。
- 先建立本地 Git 仓库；完成可分享版本并检查隐私与素材授权后，再决定是否创建公开 GitHub 仓库并启用 GitHub Pages。

## 阶段计划

### 第一阶段：完成可玩的核心版本

目标：在电脑浏览器中完成一局完整游戏。

- [x] 建立项目结构和长期计划文件。
- [x] 显示游戏地图、当前分数和操作提示。
- [x] 点击按钮后开始游戏。
- [x] 蛇能够按固定节奏自动移动。
- [x] 使用方向键或 WASD 改变方向。
- [x] 食物随机出现，且不会生成在蛇身上。
- [x] 吃到食物后蛇身增长，分数增加。
- [x] 撞墙或撞到自己后结束游戏。
- [x] 显示最终得分，并允许重新开始。
- [x] 提供简单、中等和困难三档速度；最初版本的速度作为中等档。
- [x] 为核心规则添加自动检查。

第一阶段暂不包含：手机方向按钮、主题图片、音效、暂停和最高分。

验收条件：

- 能从开始界面完成一局游戏并重新开始。
- 转向、增长、计分和碰撞判断正确。
- 快速连续按键不会使蛇在同一步内反向移动。
- 食物不会出现在蛇身体占用的格子中。

### 第二阶段：加入小朋友的创意

目标：让游戏从基础练习变成属于小朋友的作品。

- [ ] 和小朋友确定游戏名称。
- [ ] 确定主题，例如小猫吃鱼、恐龙吃蛋糕或毛毛虫吃树叶。
- [ ] 确定蛇、食物、背景和按钮的颜色。
- [ ] 收集或制作小朋友绘制的图片。
- [ ] 添加吃到食物和游戏结束时的声音，可随时关闭。
- [ ] 调整欢迎语、结束语和操作提示。
- [ ] 邀请小朋友连续试玩三局，记录最影响体验的问题。

验收条件：

- 小朋友能够说清楚哪些创意是自己决定的。
- 图片和声音不会影响游戏操作和内容辨认。
- 素材不包含真实姓名、学校、班级、住址或未经同意公开的照片与声音。

### 第三阶段：适配移动设备并公开分享

目标：让家人和同学通过链接直接游玩。

- [ ] 添加四个大号触屏方向按钮。
- [ ] 检查手机竖屏、手机横屏、平板和电脑显示效果。
- [ ] 防止页面滑动或误触影响游戏。
- [ ] 完成发布前的隐私与素材授权检查。
- [ ] 确定仓库公开方式和许可证。
- [ ] 创建远程 Git 仓库并发布网页。
- [ ] 用真实分享链接完成至少两台设备的试玩。

验收条件：

- 无需安装或登录即可进入游戏。
- 键盘和触屏均可完成一局游戏。
- 页面中没有不适合公开的信息。
- 分享链接能够稳定打开并重新开始游戏。

## 后续功能候选

这些内容不进入前三个阶段的必做范围，应在基础版本发布后按试玩反馈选择：

- 在玩家自己的设备上保存最高分。
- 暂停和继续。
- 障碍物或不同地图。
- 特殊食物和临时奖励。
- 多套角色外观。
- 分享成绩图片。

暂不考虑在线排行榜和多人联网，因为它们需要服务器、数据管理和更多隐私保护工作。

## 小朋友可以参与的工作

- 给游戏、角色和食物取名字。
- 在纸上画角色、食物、背景和按钮。
- 选择颜色以及成功、失败时显示的话。
- 录制或挑选简短音效，但公开前由成年人确认。
- 每完成一个小阶段试玩三次，说出最喜欢和最想改变的地方。
