# 动物追追乐

这是一个和小学一年级小朋友一起创作的网页小游戏。玩家可以更换主角和追逐目标，在电脑上使用方向键、在手机和平板上滑动游戏地图游玩。

## 当前玩法

- 点击“开始游戏”。
- 页面显示当前主角和目标，点击“更换”打开图形选择面板。
- 主角可以选择小蛇或小猫，目标可以选择苹果或老鼠。
- 选择简单、中等或困难模式；简单模式为默认选项。
- 电脑使用键盘的上下左右键控制方向，触屏设备在游戏地图内向对应方向滑动。
- 抓到目标后角色轨迹变长，分数增加。
- 撞到墙或自己的身体后游戏结束。
- 点击“再玩一次”重新开始。

简单、中等和困难模式分别约每 400、280 和 180 毫秒移动一格。游戏过程中打开主角或目标选择面板会临时暂停，关闭后自动继续，当前分数不会清空。

游戏地图会根据浏览器空间自动调整：宽屏使用较大的地图和双栏布局，手机使用无需页面滚动的紧凑布局。手机横屏会切换为双栏，游戏开始后暂时收起设置区域。Canvas 会同步调整绘制分辨率，放大后仍保持清晰。

## 如何运行

直接用浏览器打开 `index.html` 即可游玩。

开发检查需要电脑已安装 Node.js：

```bash
npm test
```
