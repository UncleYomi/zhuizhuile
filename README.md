# 贪吃蛇小游戏

这是一个和小学一年级小朋友一起创作的网页贪吃蛇游戏。当前完成了第一阶段：电脑键盘可玩的核心版本。

## 当前玩法

- 点击“开始游戏”。
- 选择简单、中等或困难模式；简单模式为默认选项。
- 使用键盘的上下左右键控制方向。
- 吃到食物后身体变长，分数增加。
- 撞到墙或自己的身体后游戏结束。
- 点击“再玩一次”重新开始。

中等模式保留了最初版本的移动速度，简单模式更慢，困难模式更快。游戏过程中切换难度会立即改变速度，但不会清空当前分数。

## 如何运行

直接用浏览器打开 `index.html` 即可游玩。

开发检查需要电脑已安装 Node.js：

```bash
npm test
```
