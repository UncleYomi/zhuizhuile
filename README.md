# 动物追追乐

这是一个和小学二年级小朋友一起创作的网页小游戏。玩家可以更换主角和追逐目标，在电脑上使用方向键、在手机和平板上滑动游戏地图游玩。

## 当前玩法

- 点击“开始游戏”。
- 页面显示当前主角和目标，点击“更换”打开图形选择面板。
- 主角可以选择小蛇、小猫、小鸡、猎豹或小朋友，目标可以选择苹果、老鼠、虫子、鹿或小青蛙。
- 主角和目标都支持添加一张自定义图片；图片会自动居中裁成正方形，只保存在当前设备，不会上传。
- 选择简单、中等或困难模式；简单模式为默认选项。
- 地图可以选择开阔场地或迷宫；迷宫中主角从入口出发，目标固定在出口。
- 电脑使用键盘的上下左右键控制方向，触屏设备在游戏地图内向对应方向滑动。
- 抓到目标后角色轨迹变长，分数增加。
- 页面会按难度保存当前设备上的最高分，不需要注册或登录。
- 开始、抓到目标和游戏结束时会播放简短音效，可通过顶部按钮关闭。
- 游戏中可以点击暂停按钮；电脑也可以使用空格键暂停和继续。
- 撞到墙或自己的身体后游戏结束。
- 迷宫模式中撞到内部墙壁也会结束，找到出口目标则通关。
- 点击“再玩一次”重新开始。

简单、中等和困难模式分别约每 400、280 和 180 毫秒移动一格。游戏过程中打开主角或目标选择面板会临时暂停，关闭后自动继续，当前分数不会清空。切换浏览器页面或让手机进入后台时会自动暂停；继续前显示简短的 3、2、1 倒计时。

游戏开始后不能切换难度，结束后可以重新选择，这样三个难度的最高分能够分开记录。游戏地图会根据浏览器空间自动调整：宽屏使用较大的地图和双栏布局，手机使用无需页面滚动的紧凑布局。手机横屏会切换为双栏，游戏开始后暂时收起设置区域。Canvas 会同步调整绘制分辨率，放大后仍保持清晰。

## 如何运行

直接用浏览器打开 `index.html` 即可游玩。

开发检查需要电脑已安装 Node.js：

```bash
npm test
```
