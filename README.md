# 动物追追乐

这是一个和小学一年级小朋友一起创作的网页小游戏。玩家可以更换主角和追逐目标，在电脑浏览器中使用方向键游玩。

## 当前玩法

- 点击“开始游戏”。
- 主角可以选择小蛇或小猫。
- 目标可以选择苹果或老鼠。
- 选择简单、中等或困难模式；简单模式为默认选项。
- 使用键盘的上下左右键控制方向。
- 抓到目标后角色轨迹变长，分数增加。
- 撞到墙或自己的身体后游戏结束。
- 点击“再玩一次”重新开始。

主角、目标和难度都可以在游戏过程中切换，不会清空当前分数。中等模式保留了最初版本的移动速度，简单模式更慢，困难模式更快。

## 如何运行

直接用浏览器打开 `index.html` 即可游玩。

开发检查需要电脑已安装 Node.js：

```bash
npm test
```
